# HeatIA-Recife
Previsão e Classificação de Acidentes de Trânsito em Recife
Este repositório contém um projeto de análise preditiva e classificação de acidentes de trânsito na cidade de Recife, utilizando redes neurais profundas (PyTorch), aprendizado de máquina e mapas interativos para prever locais de maior risco em 2025.

Descrição do Projeto
Este projeto foi desenvolvido para analisar padrões históricos de acidentes e prever áreas críticas com base em modelos avançados de inteligência artificial. Além disso, utilizamos um modelo de classificação para categorizar os acidentes previstos em baixo, médio e alto risco, permitindo uma visão estratégica para a tomada de decisões de segurança viária.

 Objetivos
 
✅ Treinar um modelo preditivo para estimar acidentes em Recife em 2025.

✅ Criar um mapa de calor interativo exibindo os locais de maior risco.

✅ Classificar os acidentes previstos em diferentes níveis de severidade.

✅ Gerar insights para políticas públicas e ações de prevenção no trânsito.

Tecnologias e Ferramentas

📌 Linguagem: Python

📌 Frameworks: PyTorch, Scikit-Learn

📌 Bibliotecas: Pandas, NumPy, Folium, Geopy

📌 Visualização: Mapas de Calor Interativos
